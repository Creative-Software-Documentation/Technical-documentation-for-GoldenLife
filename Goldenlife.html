Golden life Platforn API (FULL PROJECT OVERVIEW)

About this API

This Laravel based REST API powers a multi-role Golden life Platforn that connects Students (customers/resellers), Vendors (product sellers) and Instructors (course sellers) under a single system. The platform combines e-commerce (product purchase & delivery), an online course/learning marketplace, a digital wallet with send-money/withdraw features, subscription plans, share purchase, and a support/ticketing system — all controlled from one Admin Panel.

How the API is organized

Every route below is taken directly from routes/api.php. Routes are grouped by the role that consumes them (Student, Vendor, Instructor) and by feature (Product, Course, Location, Bank, Notification, FAQ, Ticket, Chat, Subscription, Share, Hospital). Most protected routes use Laravel Sanctum (auth:sanctum) issued after OTP/Password login; a smaller set of legacy/admin-facing routes use API token guard (auth:api). Routes without any tag below are public.

Base URL & Requirement

Framework

Built on Laravel and consumed by web / mobile apps as a JSON REST API. All endpoints below are relative to your API base URL, e.g. https://yourdomain.com/api.

Authentication Guards
  • auth:sanctum — Token issued to Student / Vendor / Instructor after login (send as Authorization: Bearer <token>).
  • auth:api — Token guard used mainly on legacy/admin-consumed transaction & order reporting routes.
  • public — No token required.
Response Format

All endpoints are expected to return JSON. Standard verbs used across the API:

  • GET Read / list data
  • POST Create, login, or action-trigger endpoints
  • PUT Update a specific resource
  • DELETE Remove a resource
